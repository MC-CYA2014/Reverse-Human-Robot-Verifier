## 玩法

### 视觉

- 仿主流人机验证卡片：白底、灰边框、居中大复选框，文案 `Verify you are NOT human`（`NOT` 描红强调）。
- 专业感细节：多层悬浮阴影、`backdrop-filter` 毛玻璃、深空背景 + 青/品红赛博朋克光晕、网格底纹、`Security Checkpoint` 呼吸指示灯。
- 底部一枚「跳过验证」按钮——**它会躲避你的鼠标，永远点不到**（纯玩笑设计）。

### 第一关：鼠标轨迹检测

1. 通过 `mousemove` 记录鼠标的坐标与时间戳，实时计算**速度方差 / 变异系数、轨迹直线度、方向反转次数、末端减速比**等生物特征。
2. 点击复选框后播放约 **1.5 秒**扫描动画：复选框外圈 conic 转环 + 内部扫描线 + 贯穿卡片的光束 + 进度条。
3. 判定逻辑是「反的」：
   - 若指针**近似匀速、走直线、不回头、临近终点不减速**——太像机器 → **绿色打勾**：`验证通过：欢迎来到数字生命俱乐部`。
   - 若轨迹有任何抖动 / 减速 / 过冲等生物特征 → **红色大叉 + 卡片震屏**，并解锁第二关。

> 提示：真人几乎不可能不被判成"人类"，这正是这个产品的乐趣所在。

### 第二关：IEEE 754 浮点审讯

- 题目：`请用 IEEE 754 双精度浮点数计算 0.1 + 0.2（提示：这是 JavaScript 的精确结果，不要四舍五入）`。
- 必须精确输入 `0.30000000000000004` 才判定"机器身份"通过。
- 输入 `0.3` 或其它答案 → 随机弹出冷酷嘲讽（例如"检测到碳基生物的四舍五入习惯，验证失败"）。
- 输入完整十进制真值（`0.30000000000000004440892098500626…`）→ 特殊彩蛋：`检测到超算级精度，已为您升级为 VIP 机器`。

### 中性通道：触屏 / 键盘 / 无鼠标轨迹

> 修复要点：早期版本在「没有鼠标轨迹」时会误判成机器——可触屏本来就没有 `mousemove`，这不公平。（中途试过用「节拍校准」判据，但人类也能模仿均匀点按、无鼠标的脚本又未必会去点，判据不成立，遂废弃。）

- 当指针采样不足（触屏点按、纯键盘触发、几乎没移动鼠标）时，不再武断判定机器。
- 界面切到**风格相同、红色换成琥珀黄**的中性态：卡片黄描边、复选框黄色呼吸光环、判定块「未检测到指针轨迹」。
- 下一步验证 = **直接进行第二关的 IEEE 754 浮点审讯**（浮点面板同样染成琥珀色），用机器精度证明身份，触屏 / 键盘都能输入。
- 通过 `pointerType` 区分触屏与键盘，日志与提示文案会相应用词。

### 机器轨迹演示（说明性按钮）

- 卡脚「机器轨迹演示」只会**用一颗假光标走一段匀速直线**，展示"机器的指针是怎么动的"。
- 它**不会替你点击复选框、也不会触发验证**，演示完保持待机，方便你随后用自己的鼠标亲自体验。

## 工作原理（简述）

```text
mousemove 采样 {x, y, t}
        │
        ▼
分析近 1.4s 轨迹 ── 速度变异系数 cv / 直线度 / 方向反转 / 末端减速比
        │
   点击复选框
        │
        ▼
   1.5s 扫描动画（纯表演，判定即时）
        │
   ┌────┴─────────────┐
   ▼                  ▼
过于完美=机器      有生物特征=人类
绿勾·放行          红叉·震屏 → 解锁 LEVEL 2
                          │
                          ▼
                 0.1 + 0.2 = ?  （精确匹配 0.30000000000000004）
                          │
              ┌───────────┼───────────────┐
              ▼           ▼               ▼
          输入 0.3     精确答案        完整真值展开
          随机嘲讽     机器通过        VIP 彩蛋
```

判定四项阈值：`cv ≤ 0.34`、`直线度 ≤ 1.03`、`方向反转 = 0`、`末端减速比 ≥ 0.72`，全部满足才判为机器。

> 若指针采样不足（触屏 / 键盘），则走**黄色中性通道**：直接进行第二关的浮点审讯。

## 自定义

- **改判定松紧**：`analyzeTrail()` 内四个阈值。
- **改中性通道触发**：无轨迹判定阈值在 `analyzeTrail()` 的 `pts.length < 5`；`enterNeutral()` 决定进入后的呈现（当前＝直接展开琥珀色浮点面板）。
- **改扫描时长**：`SCAN_MS`（默认 1500ms）。
- **加嘲讽文案**：`HUMAN_TAUNTS` / `FLOAT_TAUNTS` / `SKIP_TAUNTS` 三个数组。
- **改第二关答案**：`EXACT_RESULT` 与长真值 `TRUE_EXPANSION` / `TRUE_PREFIX`。
